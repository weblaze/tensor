# DayCounter

Where a build stands against plan: "Day 20 / 45" with one segment per planned working day.

Segments: `tn-day__seg--done` for days elapsed on plan, `tn-day__seg--late` for days the plan has slipped, plain for days remaining. The note under it says the slip in days and the handover date change ("2 days behind plan · handover 4 Oct → 6 Oct"); on plan, it says "On plan · handover 4 Oct".

Shown at the top of a project screen and the doctor report. The consumer provides start date, planned days, elapsed days and slip.
